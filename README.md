👤 Age and Gender Prediction App using CNN

A Deep Learning–based application that predicts a person’s age and gender from facial images using a Convolutional Neural Network (CNN). The trained model is deployed as an interactive web application for real-time predictions.

📌 Overview

This project uses CNNs to classify human faces into:

Gender: Male / Female

Age Group: Ranges such as
0–2, 4–6, 8–13, 15–20, 25–32, 38–43, 48–53, 60+

The application:

Takes an input face image

Detects the face region

Resizes it to a fixed shape

Passes it to a trained CNN model

Outputs Age & Gender predictions

✨ Features

✅ Predicts age and gender from any human face image
✅ Built using TensorFlow / Keras CNN
✅ Supports training and deployment modes
✅ Exportable trained model in .h5 format
✅ Optional Flask / Streamlit web interface for live demos

🧰 Tech Stack

Language: Python

Deep Learning Framework: TensorFlow / Keras

Libraries: NumPy, OpenCV, Matplotlib, Scikit-learn

Deployment (Optional): Flask / Streamlit

IDE: Jupyter Notebook / VS Code
